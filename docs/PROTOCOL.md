# Протокол обмена AEB MP48

Получен по записи USB-трафика между штатной программой и блоком (кабель PL2303) и сверен с txt-логами самой программы. Описано только то, что видно в записях; часть полей и команд не расшифрована.

## Линия

- **9600 бод, 8N1**, DTR и RTS выключены.
- Однопроводная линия (похожа на K-line): **всё отправленное возвращается эхом**, затем приходит ответ блока. При разборе первые N байт приёма (N — длина запроса) нужно пропустить.
- Блок отвечает только на запросы. Короткая команда — ~10–15 мс, запрос параметров с ответом — ~45 мс.

## Формат

- Запрос: `[команда] [параметры…] [КС]`, КС = сумма всех предыдущих байт mod 256.
- Ответ OK: `53 ('S') [N] [N байт данных] [КС]`, КС = сумма `53`, `N` и данных mod 256.
- Ответ «ошибка»: `CA 01 [код] [КС]`. Встречались коды `0x10` (команда/адрес не поддерживается) и `0x01` (неверная длина запроса).

## Команды

| Команда | Пример | Смысл |
|---|---|---|
| `00 02` | `00 02 02` → 4 байта | идентификация блока |
| `00 25` | `00 25 25` → 1 байт | версия/тип |
| `00 01` | `00 01 01` | конец инициализации / завершение сеанса |
| `01 xx yy` | `01 00 3A 3B` → пусто | служебная, отправляется в начале сеанса |
| `09 lo hi` | `09 33 00 3C` → 1–2 байта | чтение переменной по номеру |
| `0A lo hi i` | `0A F1 00 01 FC` | чтение элемента массива |
| `29 lo hi` | `29 5C 01 86` → до 60 байт | чтение блока (карты, таблицы) |
| `2A lo hi i` | `2A 54 00 00 7E` → 12 байт | чтение строки карты |
| **`48 01`** | `48 01 49` → 34 байта | **текущие параметры** |
| `35 lo hi b0 b1 b2 b3` | `35 03 00 84 34 09 00 F9` → пусто | запись 4-байтной переменной (используется для переключения топлива, см. ниже) |
| `37 …` | — | запись служебной строки — **в приложении не используется** |

Для чтения текущих параметров авторизация не нужна.

## Кадр текущих параметров (ответ на `48 01`, 34 байта, little-endian)

| Байты | Параметр | Формула |
|---|---|---|
| 0–1 | Обороты | u16, об/мин |
| 2 | Лямбда | b × 5 / 255, В |
| 3 | не расшифрован (растёт с MAP) | |
| 6–7 | Время впрыска газа | u16 / 390,625, мс (тик 2,56 мкс) |
| 8–9 | Время впрыска бензина | u16 / 390,625, мс |
| 10 | бит `0x08` — момент перехода на бензин | |
| 11 | Состояние: `0xA0` бензин, `0xA8` газ выбран (ожидание условий), `0xB0` работа на газу | бит `0x08` — газ выбран, `0x10` — на газу, `0x04` — отсечка топлива (Tб = Tг = 0), `0x01` — короткий бензиновый импульс (< ~1,5 мс) в переходе, газ держится прежним, `0x20` — сброшен первые ~40–90 с после пуска (смысл не выяснен) |
| 12 | Температура редуктора, сырое значение NTC | таблица ниже |
| 13 | не расшифрован (меняется только когда выбран газ) | |
| 14–15 | Давление газа | u16 / 1000, бар |
| 16 | Температура газа, сырое значение NTC | таблица ниже |
| 17–18 | MAP | u16 / 1000, бар |
| 19 | не расшифрован (меняется только когда выбран газ) | |
| 24–25 | Время газа 2 (вероятно, другой цилиндр/банк) | u16 / 390,625, мс |
| 28–29 | Время бензина 2 | u16 / 390,625, мс |
| остальные | нули в проверенных записях (датчик уровня не подключён) | |

Таблица NTC (сырое значение для −20, −15 … 125 °C с шагом 5):
`231 224 216 206 195 183 170 156 142 128 114 101 89 78 68 59 51 44 38 33 29 25 22 19 16 14 12 11 10 8`.
Температура — линейная интерполяция, расхождение со штатной программой не больше 1 °C.

Проверка на 1738 кадрах (`test/vectors.txt`): обороты, время газа, давление, MAP и температуры совпадают с логом штатной программы на 100 % (в пределах точности лога), лямбда и время бензина — на 99,9 %.

## Карта коэффициентов K

- Ось времени бензина: `29 37 00 60` → 24 байта, 12 × u16 в тиках 2,56 мкс (÷ 390,625 = мс), например 2,0 · 2,5 · 3,0 · 3,5 · 4,5 · 6,0 · 8,0 · 10 · 12 · 14 · 16 · 18 мс.
- Ось оборотов: `29 3D 00 66` → 12 × u16, об/мин (500 … 6000).
- Строки карты: `2A 54 00 i КС`, i = 0…12 → 12 байт, K × 100 (например `88` = 1,36). Строка i соответствует i-й точке оси Tб; строка 12 — скрытая (повторяет последнюю).
- Блок интерполирует карту билинейно по Tб и оборотам.

## Переключение газ/бензин

Режим хранится в переменной 3 (4 байта, читается `29 03 00 2C`, например `84 24 09 00`). В байте 1: бит `0x10` — выбран газ, бит `0x08` — «строб» смены. Штатная программа записывает четыре значения подряд командой `35`, меняя только эти два бита:

1. текущее значение;
2. текущее | `0x08`;
3. (цель) | `0x08`, пауза ~0,5 с после шага 2;
4. цель, пауза ~0,5 с после шага 3.

Бензин → газ: `24 → 2C → 3C → 34`. Газ → бензин: `34 → 3C → 2C → 24` (байт 1). Блок отвечает на каждую запись `53 00 53`. Результат виден в байте 11 кадра параметров: газ выбран — `0xA8`, затем `0xB0` после выполнения условий перехода.

## Минимальный сеанс (только чтение)

1. Порт 9600 8N1, DTR = 0, RTS = 0.
2. `00 02 02` — проверка связи (ответ `53 04 …`), затем `01 00 3A 3B`.
3. Циклически `48 01 49` раз в 100 мс: отбросить 3 байта эха, проверить `53 22`, длину и КС.
4. При завершении — `00 01 01`.
