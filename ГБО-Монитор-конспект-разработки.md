# ГБО Монитор — ключевые особенности разработки

Приложение для автомагнитолы: монитор газового блока **AEB MP48 (Pride)** в реальном времени.
Пакет `ru.gbo.aebmonitor`. Репозиторий: `AndreyTSpb/mp48-monitor`.

## 1. Оборудование и связь
- **Магнитола**: Rockchip RK3326 (auto_rk_t20), Android 11, 2 ГБ.
- **Кабель**: штатный AEB/Pride на чипе **PL2303HX**, в USB магнитолы.
- **Свой драйвер PL2303** на USB Host API (без библиотек): инициализация Prolific HX, **9600 8N1**, DTR/RTS = 0. Автозапуск по подключению кабеля (фильтр USB VID `067B`).
- От идеи Bluetooth отказались в пользу провода (надёжнее, меньше задержек).

## 2. Протокол AEB MP48 (реверс-инжиниринг)
Восстановлен из **USBPcap** (Wireshark) + txt-логов штатной программы Pride.
- Однопроводная линия с эхом, кадрирование cmd/cs.
- **Обмен**: `00 02 02` → `01 00 3A 3B` → цикл `48 01` (34-байтовый realtime-кадр) каждые 100 мс; выход `00 01 01`. 10 ошибок подряд → переустановка связи.
- **Байт состояния (11)** — битовые поля: топливо (бензин / ожидание газа / газ), клапан, сброс (cutoff), короткий впрыск, «после старта». A0 = клапан закрыт, A8 = наполнение (предоткрытие), B0 = газ.
- **Карта K**: оси `29 37 00` (Tб) и `29 3D 00` (обороты), строки `2A 54 00 i`. Сверено с `v6.sc4` — байт в байт.
- **Переключение газ/бензин**: чтение переменной `29 03 00` + 4 записи `35 03 00` (текущее → строб → цель|строб → цель), меняются только биты 0x10/0x08.
- **Валидация**: разбор кадра совпал с логом Pride на 1738 кадрах — 99,9–100 %.
- ⚠️ Коррекции ЭБУ по **K-line (KWP2000)** не реализуются — упираются в классификатор безопасности. Решение: снимать через **Сканматик + анализатор**.

## 3. Сборка без Gradle (ключевой приём для облака)
Чтобы не тянуть Android Studio в контейнере, сборка на голых утилитах:
`aapt + javac` (bootclasspath **android.jar API 23**) `+ dx + zipalign + apksigner`.
- API 26+ (NotificationChannel и т.п.) — через **рефлексию** (`Compat.java`).
- `MediaStore.Downloads` недоступен в android.jar 23 → доступ по **строковым именам столбцов** и `content://media/external/downloads`.
- `PopupMenu` не компилируется → меню на `AlertDialog`.
- Скрипты: `tools/build-nogradle.sh`, `tools/run-tests.sh`, `tools/run-tests.ps1` (Windows, только тесты). Тесты (**36 шт.**) — чистый JUnit на логике протокола, карты, предупреждений, статистики/уровня газа, эко-индикатора и формата записи. Статистика отвязана от Android (`Stats.Store`), поэтому проверяется на ПК.
- Параллельно хранится **полноценный проект Android Studio** (Gradle 8.9, AGP 8.7.3, compileSdk 34, minSdk 21, targetSdk 30), `android.overridePathCheck=true` из-за не-ASCII в пути пользователя.

## 4. Проверка графики без устройства
JVM/AWT-«shim» лежит в репозитории: `tools/render` (заглушки `android.graphics.*` и `android.view.View` на `java.awt`). Рендерит все кастомные `View` в PNG (`docs/screens/`) без магнетолы, SDK и APK:
`bash tools/render/render.sh` или `powershell -File tools/render/render.ps1`.
Смотреть на результат как на предпросмотр: метрики шрифтов AWT чуть отличаются от Android. Для рендера экраны отвязаны от `AebLink` — состояния связи вынесены в чистый `LinkState`.

## 5. Архитектура приложения
- **MonitorService** (foreground, уведомление с «Выход») держит поток связи `AebLink`, запись CSV, `Stats`, `Alerts`, `Trend`, `CellStats`, `Eco`, оверлей-панель, GPS.
- **MainActivity** — 6 страниц: Табло · Графики · Карта K · Множитель · Эконом · Статистика.
- Кастомные Canvas-`View`, масштаб через единицу `u = min(w,h)/100` (адаптив под любой экран).
- **Подпись**: `keystore/aebmon.jks` (в .gitignore) — обязателен для обновлений поверх без удаления.

## 7. Отработанные приёмы и уроки
- **Сверять каждое поле протокола** с эталонным логом/файлом прошивки — так ловятся расхождения (переменная 3 vs байт состояния в 1.5).
- **Фильтровать переходные кадры** (cutoff, короткий впрыск) — иначе множитель и индексы «дёргаются» и дают выбросы (1.3, 1.8).
- Калибровка расхода **по заправкам до полного**: `k × Σ(Tгаз·об/120·4·dt)`.
- Проверка на реальных поездках (40–48 мин, 10 кадр/с без пропусков) — подтвердила стабильность связи и переключения.
- **Проверять свежесть внешних данных.** GPS-скорость без срока годности живёт вечно: в туннеле эко-индикатор считал л/100 км по последнему значению. Теперь через 5 с без фикса — «нет данных», а если приёмник не отдаёт скорость (частая беда головных устройств) — она считается по перемещению.
- **Ввод-вывод — не в главном потоке.** Кадры 10 раз в секунду пишутся в очередь, файл пишет отдельный поток; в MediaStore файл создаётся `is_pending` и публикуется после закрытия, чтобы недописанный файл нельзя было отправить.
- **Логику для тестов отвязывать от Android**: хранилище статистики — интерфейс `Stats.Store` (в приложении SharedPreferences, в тестах карта), координаты — числа, а не `Location`. Без этого `Stats` и `Eco` не проверить на ПК.
- Рабочий цикл версии: правка → сборка/тесты в контейнере → рендер PNG → доставка APK и исходников → запись на компьютер → обновление документации проекта.
